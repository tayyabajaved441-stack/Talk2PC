# Talk2PC

A voice assistant made in Python that follows your commands.

## Features
- 🎤 Voice commands with `speech_recognition`
- 🔊 Text to speech with `pyttsx3` 
- 🌐 Opens Google: say "open google"
- 📺 Opens YouTube: say "open youtube"

## How to Run
```bash
python TalkPC.py
```
## Install Requirements 
pip install speechrecognition pyttsx3
